# Project: Rubik's Cube (3D, interactive)

_Last updated: 2026-09-13 by O-001_

## Objective

A Python desktop app showing a 3x3x3 Rubik's Cube that can be orbited with the
mouse, turned face-by-face by dragging a sticker, scrambled randomly, and
un-scrambled back to solved.
